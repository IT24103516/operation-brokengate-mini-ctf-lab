\# Operation BrokenGate – Mini CTF Cyber Lab



Operation BrokenGate is a Docker-based mini cybersecurity CTF lab designed for practicing basic web enumeration, SSH access, Linux privilege escalation, and flag-based challenges in a safe local environment.



\## Features



\- Web enumeration challenge

\- Hidden source-code flag

\- `robots.txt` discovery

\- Backup clue discovery

\- SSH login challenge

\- User flag

\- Linux privilege escalation

\- Root flag

\- Isolated Docker network
